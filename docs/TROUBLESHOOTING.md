# Troubleshooting

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| OAuth reports `redirect_uri_mismatch` or rejects the callback. | The APS app registration has a different port or path. Autodesk tutorial examples often use port 8080; this app uses 3000. | Register `http://localhost:3000/api/aps/callback` on the APS app and set `APS_CALLBACK_URL` to that exact URL. Restart the app after changing `.env.local`. |
| Sign-in completes, then the callback says **Access denied**. | The signed-in Autodesk account's Data Management hub list does not include `FORMA_HUB_ID`. | Sign in with a member of the target hub, or configure a hub that the account can reach. Enter the hub ID without the `b.` prefix. A hub administrator can add the account. |
| The account is in the hub, but ACC/Forma API calls still fail. | The APS app's Client ID has not been provisioned as a custom integration for the ACC/Forma account. Developer Portal registration alone is insufficient. | Ask a hub administrator to add the Client ID under **Hub Admin › Custom Integrations**. Follow [Autodesk's provisioning guide](https://get-started.aps.autodesk.com/#provision-access-in-other-products). Then sign in again. |
| **Sync projects** succeeds, but Tools says **0 of 21 enabled**. | Project sync only reads the Admin API project list. Tools reads CSV tables from a separately uploaded Insight Data Connector ZIP. | In Autodesk Construction Cloud, run a Data Connector extraction in **Insight**, download the ZIP, then use **Tools → Choose File → Upload extract** in this app. |
| A general Insight URL says **No access** or Insight is missing from hub navigation. | Insight is normally opened from an ACC project or the product picker; a generic hub-level URL may not identify a project. Permissions can also matter. | Open a project in the target hub, select **Insight** from the product picker, then **Data Connector** in Insight's left sidebar. If needed, use the project dashboard URL pattern `https://acc.autodesk.com/insight/accounts/<hubId>/projects/<projectId>/my-dashboard` with real IDs for a project you can access. See [Autodesk's Data Connector guide](https://help.autodesk.com/cloudhelp/ENU/Docs-Insight/files/Data_Connector.html). |
| An Insight extraction does not appear under this app's **Extracts** page. | Insight's manual ZIP export and this app's APS request/ingest flow are independent. | Watch Insight for the request you made there. Autodesk emails when the ZIP is ready (the Hub Admin received it in the reviewed setup); use its **View in Data Connector** link, download the ZIP, and upload it on **Tools**. This app's **Extracts** page tracks requests submitted inside this app. |
| Some tool dashboards remain grey after uploading a ZIP. | The ZIP lacks those tools' required CSVs. A project extract may include only modules used by that project. | Check the missing source CSV named on each card; run an Insight extraction that includes the relevant data if available. A CSV that exceeds the 400,000-row import cap is marked as truncated in Tools. |
| `npm test` cannot remove its temporary SQLite directory on Windows. | An older version left the process-local SQLite connection open. | Update to the version with `closeDb()` in the dashboard test cleanup, then run `npm test` again. |
| A completed activity job reports individual file failures. | A CSV could not be downloaded or parsed, or exceeded the 400,000-row per-file safety cap. Other valid activity files may still have loaded. | Inspect the failed file names shown after ingestion and the job's error field. Correct the source issue and retry **Ingest**; imported rows are deduplicated. |

See [Usage](USAGE.md) for both data paths and [Limitations](LIMITATIONS.md) for storage and extract limits.
