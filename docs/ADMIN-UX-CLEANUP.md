# Administrative usability in the demo

The public sample carries the portfolio navigation and readability improvements from Forma Hub Lens into a separate synthetic experience. It opens directly without Autodesk sign-in and makes no APS API calls.

## Navigation and chart readability

Six main workspaces group the features. Search and Saved are header utilities. Project, person, and company profiles connect related views. The Internal badge is removed.

All 21 dashboards use chart components that keep labels at normal text sizes. Category labels wrap, status legends retain names, and time charts provide tabular values. Issues root-cause and RFI-category views use readable category/share presentation.

## Project inventory

**Project members** counts assigned fictional memberships. **Active people (observed)** counts activity identities in the sample window. Sorting can compare project name, status, membership, observed activity, event volume, services, and sheets. Missing data remains distinct from a known zero.

## Selection

Multi-item selectors use left-hand checkboxes and Select all shown. Filtering preserves selected items outside the visible list. Selection counts and limits remain visible. Product choices demonstrate the administrative preview and are not subscription balances.

## Identity and company labels

Fictional company, user, and role names are resolved from the sample records where possible. Unknown IDs remain labeled as unknown rather than assigned arbitrary identities. Company profiles connect sample people and projects.

## Administrative boundary

Add/remove membership, project creation, and archiving use the browser-only action simulator. Configure, preview, confirm, run, and inspect simulated results. No invitation, subscription assignment, company edit, live project change, or Autodesk audit entry occurs.

The provisioning recipe is a read-only example. Browser-local saved views, favorites, and review decisions do not create monitoring or durable administrative records.
